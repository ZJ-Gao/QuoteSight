Shortcuts and actions
  • Esc: close the open tab
  • EscEsc: clear the current search and start over
  • Enter: run the search from the search box
  • Select text on the PDF: save it as a supports / refutes / context highlight, or add it to the vocabulary
  • PDF bar ⋯ → Colors and opacity: change the stance colors
  • Max papers: the most relevant papers the agent picks (up to 20)
  • Max quotes per paper: the most quotes shown from each paper, ranked by relevance
  • Min relevance: show only quotes at or above this level; applies at once, no new search
